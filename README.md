# Fling 3D ✈️

لعبة طيران ثلاثية الأبعاد خفيفة تعمل في المتصفح دون مكتبات خارجية.

## التشغيل
افتح `index.html` في متصفح يدعم WebGL. يمكن تنزيل المستودع كاملًا وتشغيل اللعبة دون اتصال بعد التنزيل.

## التحكم
- عصا اللمس: التوجيه والميل.
- زيادة السرعة: رفع قوة المحرك.
- فرامل: تقليل قوة المحرك.
- إعادة: إعادة وضع الطائرة.

## ملاحظات
الأداء ومعدل الإطارات يعتمدان على الجهاز والمتصفح. الوصول إلى 120 إطارًا/ثانية ليس مضمونًا على كل الأجهزة.

# Pocket Drive 3D

A single-file mobile driving experiment. The complete game interface, styles, controls, and gameplay code are inside `index.html`.

## Run
Open `index.html` in a browser. Three.js is loaded from jsDelivr, so the first launch needs an internet connection. If the 3D library or WebGL is unavailable, the file starts a simpler Canvas fallback mode.

## Controls
- Left / right: steer
- Gas: accelerate
- Brake: slow down
- Pause: pause the drive
- Keyboard: arrow keys, A/D, Space

The game is an original prototype and does not include Dr. Driving source code or extracted proprietary assets.

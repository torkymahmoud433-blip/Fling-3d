# City assets

This starter scene currently uses lightweight procedural placeholder buildings and roads so it can be opened before the Kenney package is imported.

To add Kenney City Kit: Roads:
1. Extract the Kenney package on your device or computer.
2. Copy its GLB models and required texture files into `assets/kenney_city_roads/`.
3. Open this project in Godot 4 and let the editor import the assets.
4. We can then replace the placeholder road/building meshes with the exact GLB models.

The project uses the Compatibility renderer to keep the Web export path available. Web export still requires a Godot 4 Web export template.
